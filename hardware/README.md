# Hardware Files

This folder contains all the necessary files to manufacture the LoRa32++ V1.3 PCB.

*   `easyeda/` - The original EasyEDA project files. You can import these if you need to modify the schematic or PCB layout.
*   `gerber/` - The ready-to-manufacture Gerber files. Upload the `.zip` file from this folder to a PCB manufacturer like JLCPCB or PCBWay.
*   `bom/` - The Bill of Materials (BOM) in CSV format for parts ordering.

**Warning:** Always verify the Gerber files in a viewer (like Gerber Viewer in EasyEDA or KiCad) before ordering.
